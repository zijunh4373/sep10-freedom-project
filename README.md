# SEP10 Freedom Project
by **X**

## Context
I am a student at [HSTAT](https://www.hstat.org/) in the [Software Engineering Program](https://hstatsep.github.io/). The "Freedom Project" for SEP10 is a year-long project all about making a website that informs the viewer of the current and future innovations in the topic of my choosing.

For my project, I chose the topic of **Soccer and Technology**. I chose this topic because soccer is a sport that I enjoy, and I wanted to learn more about how technology is changing the way the game is played. Technology has become an important part of modern soccer, from goal-line technology and Video Assistant Referee (VAR) to wearable fitness trackers and artificial intelligence. These innovations can help referees make decisions, help coaches analyze player performance, and improve the experience for fans.

I used HTML, CSS, Bootstrap, and GitHub to help create my website. I also chose to independently study **soccer technology and its innovations** in order to help me make my website and understand how technology is changing the sport.
